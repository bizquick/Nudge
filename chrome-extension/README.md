# Addly for Chrome

Send the page you're on to friends on Addly. Works in Chrome, Edge, Brave, and Arc on Mac and PC.

## Try it yourself (no store needed)
1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose this `chrome-extension` folder.
4. Pin it: click the puzzle-piece icon in the toolbar, then the pin next to **Addly**.

## Publish it (Chrome Web Store)
Upload `addly-chrome.zip` at https://chrome.google.com/webstore/devconsole
(one-time $5 developer registration).
