# Nudge

Send links, music, and videos to people you know — they check them out on their own time. Ported from your Figma Make file, now wired to a real database so nothing resets between sessions.

## What changed from the Figma Make export

- **Real persistence.** The app previously used in-memory mock data — it reset every time you reloaded. It's now wired to Supabase (Postgres), so reminders, reactions, and messages are saved for real and sync live across everyone testing it.
- **A working sign-in.** There was no identity system yet (`currentUser` was hardcoded to `"You"`). There's now a simple name-entry screen — no password, just a name, saved on-device — so multiple real people can use the app and see their own stuff.
- **Fixed the PWA install setup.** The manifest and service worker Figma Make scaffolded were pointing at placeholder icon files (they were actually broken — text files with a `.png` extension) and a service worker written for `npm run dev`, not a built app. Both are replaced with a proper build-time PWA setup (via `vite-plugin-pwa`) plus real icons, so "Install app" / "Add to Home Screen" works correctly on the deployed build.
- **Deployment automation.** A GitHub Actions workflow builds and publishes the app to GitHub Pages automatically on every push.

Everything else — the layout, the Nudge branding, the sidebar, reminders/reactions/archive/favorite behavior — is exactly what was in your Figma file.

## 1. Database setup

Good news: Figma Make already provisioned a real Supabase project for this file, and its URL/key are already baked into `src/app/utils/supabase/info.tsx`. You just need to create the tables in it:

1. Go to [supabase.com/dashboard](https://supabase.com/dashboard) and open the project with ID `eygojfpgisswyndusron` (sign in with the account you used in Figma — Figma Make projects appear under your linked Supabase account).
2. Open **SQL Editor → New query**, paste in the contents of `supabase-schema.sql` from this folder, and run it. This creates the `reminders`, `reminder_reactions`, and `messages` tables, turns on public read/write access matching the app's no-login design, and enables live sync.
3. That's it — no keys to copy or paste, the app is already pointed at this project.

**If that project isn't accessible to you** (e.g. it was tied to someone else's Figma account, or has been paused from inactivity): create a fresh project at supabase.com, run the same `supabase-schema.sql` there, then open `src/app/utils/supabase/info.tsx` and replace `projectId` and `publicAnonKey` with your new project's values (Project Settings → API).

**Worth knowing:** like the schema comments say, this sets fully open read/write policies — no login required, matching "just type your name." Fine for a small trusted group testing the app; not meant for a public audience.

## 2. Deploy to GitHub Pages

1. Push this whole folder to a new GitHub repository.
2. In the repo, go to **Settings → Pages**, and under **Build and deployment → Source**, choose **GitHub Actions**.
3. Push to `main` (or run the workflow manually from the Actions tab) — `.github/workflows/deploy.yml` will install dependencies, run `npm run build`, and publish the result. Your first push will trigger this automatically.
4. GitHub gives you a URL like `https://yourusername.github.io/your-repo-name/`. It can take a minute or two to go live after the workflow finishes.

## 3. Install it on your phone

- **Android (Chrome):** open the URL, tap the "Install" banner the app shows, or use the browser menu → *Install app*.
- **iPhone (Safari):** open the URL, tap the Share icon, then **Add to Home Screen**.

## Developing locally

```bash
npm install
npm run dev
```

This starts a local dev server (data still goes to the same live Supabase project, so testing locally and testing on a deployed link share the same data).

## How the pieces fit together

```

├── App.tsx                 loads/saves data via Supabase, holds top-level state
├── components/
│   ├── Onboarding.tsx       name-entry screen (new)
│   ├── QuickSendModal.tsx   the "send a reminder" form
│   ├── ReminderList.tsx     renders the list of cards
│   ├── ReminderCard.tsx     a single reminder, with reactions/messages
│   └── ui/                  shadcn component library (from Figma Make)
├── utils/supabase/
│   ├── info.tsx              your Supabase project ID + anon key (autogenerated)
│   └── client.ts             creates the Supabase client (new)
└── supabase/functions/server/  an empty edge function Figma Make scaffolded;
                                 not used — the app talks to Supabase directly
supabase-schema.sql           run this once in Supabase's SQL Editor
.github/workflows/deploy.yml  builds + deploys to GitHub Pages on push
```
